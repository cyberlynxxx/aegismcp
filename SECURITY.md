Please report security vulnerabilities to the maintainer via email at [younessmoufleh@icloud.com](mailto:younessmoufleh@icloud.com).

| Version | Supported |
| ------- | --------- |
| 3.2.x   | ✅        |

| < 3.0   | ❌        |
